# Plantillas

## Incluidas

La app trae **9 plantillas** listas para usar: historieta de 4 viñetas, tira
diaria, storyboard, tarjeta postal, avatar cuadrado, fondo de pantalla, hoja de
personaje, hoja de expresiones y **A4** para impresión.

## Usar una plantilla

Elegir plantilla crea un proyecto nuevo con el tamaño y las guías ya
configurados. Las guías de la plantilla se pueden borrar sin afectar el dibujo.
