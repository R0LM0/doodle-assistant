# Compartir

## Enlace temporal

Cada proyecto puede generar un enlace de vista previa para compartir. El enlace
caduca a los **7 días** y se puede revocar antes desde el panel de compartir.

## Qué incluye

El enlace muestra una imagen fija del frame actual, no el proyecto editable.
Para colaborar hay que exportar el archivo `.doodle` del proyecto.
