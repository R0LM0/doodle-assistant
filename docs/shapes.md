# Formas

## Disponibles

Las formas disponibles son **rectángulo**, **elipse** y **línea**. El grosor del
contorno se regula entre 1 y 50 píxeles.

## Proporciones

Mantener pulsada la tecla **Mayús** mientras se dibuja mantiene las
proporciones: el rectángulo sale cuadrado, la elipse sale circular y la línea se
limita a ángulos de 45 grados.
